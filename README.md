# TaskFlow API

A RESTful Task Management API built with Python and FastAPI.

TaskFlow API allows users to create, view, update, and delete tasks through a simple and structured REST API.

## Features

- Create tasks
- View all tasks
- View a single task
- Update tasks
- Delete tasks
- SQLite database
- FastAPI REST API
- Interactive Swagger API documentation

## Technologies Used

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Uvicorn
- Git & GitHub
